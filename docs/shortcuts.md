# Keyboard shortcuts

| Action | macOS | Windows and Linux |
|---|---|---|
| Add files | ⌘O | Ctrl+O |
| Convert, or Convert again | ⌘↩ | Ctrl+Enter |
| Open or close Settings | ⌘, | Ctrl+, |
| Open or close Help | F1 (fn F1 on most Mac keyboards), or Help > Converter Help | F1 |

The buttons show their shortcut next to the label, and the toolbar buttons show it in their
tooltip. The convert shortcut does nothing while the
list is empty or a conversion is running.
