# Keyboard shortcuts

| Action | macOS | Windows and Linux |
|---|---|---|
| Add files | ⌘O | Ctrl+O |
| Convert, or Convert again | ⌘↩ | Ctrl+Enter |
| Open or close Settings | ⌘, | Ctrl+, |
| Open or close Help | F1 | F1 |

The buttons show their shortcut next to the label. The convert shortcut does nothing while the
list is empty or a conversion is running.
